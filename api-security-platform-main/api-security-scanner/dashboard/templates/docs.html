Getting started

Xploiter scans the APIs you own for the OWASP API Top 10 vulnerabilities and returns a short, ranked list of what to fix first. It is built for developers, students, and security teams who want proof-backed findings — not noise.

1. Create an account

Sign up with your email or continue with Google. Your scans stay private to your account.

2. Run your first scan

Open New Scan, enter your API's base URL (for example https://api.example.com), tick the authorization checkbox, and press Start scan. Add a bearer token if your API needs authentication.

3. Read your top risks

When the scan finishes, the results page shows the 6 riskiest endpoints first, grouped and ranked — no repeated rows for the same endpoint.

Reading results

Findings are Confirmed (proven with evidence), Suspected (strong signals, unproven), or Informational. Each endpoint card shows a "Fix first" recommendation. Use the tabs to filter, or "Show all endpoints" for the full list.

Vulnerability checks

Xploiter tests for SQL injection, reflected XSS, BOLA/IDOR, broken authentication, CORS misconfiguration, command injection, local file inclusion, open redirect, XXE, and GraphQL introspection. See the in-app Vulnerability Guide for what each check means and how to fix it.

Exporting reports

Every finished scan can be downloaded as PDF, JSON, HTML, or SARIF 2.1.0. Reports start with the top risks, followed by the full endpoint list.

Using the CLI

Download the CLI from the landing page, generate a token in Settings → CLI token, then run python xploiter_cli.py scan https://api.example.com --token <token>.

AI Assistant

The in-app assistant explains any screen, result, or term in your language (English, Urdu, Arabic, Spanish). Always review a suggested fix before applying it.

FAQ

Is it safe to scan my production API? — Xploiter uses bounded concurrency and an endpoint budget, and only runs non-destructive probes. Scan staging first when you can.

Can I scan someone else's API? — Only APIs you own or are explicitly authorized to test. The new-scan form requires you to confirm this.

Why are some findings "Suspected"? — A finding is Confirmed only with proof (e.g. an error message or a redirected response). Anything less stays Suspected so you can judge it yourself.

Still stuck? Ask the AI Assistant. It answers in your language.
